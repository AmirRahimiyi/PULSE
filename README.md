# PULSE

**Discover. Participate. Connect.**

PULSE is a PHP and MySQL-based social platform designed to bring people together through posts, discussions, polls, and community interaction.

## Features

- User registration and authentication
- Social feed and categorized posts
- Like and bookmark functionality
- Comments and replies
- User profiles
- Search functionality
- Interactive polls and voting
- Daily challenges
- Responsive dark-themed UI

## Tech Stack

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Apache (XAMPP)

## Installation

1. Clone this repository.
2. Move the project into your local server directory.
3. Create a MySQL database named `pulse_db`.
4. Import the database structure.
5. Configure the database connection.
6. Start Apache and MySQL.
7. Open the project in your browser.
